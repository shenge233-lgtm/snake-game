# 贪吃蛇小游戏 (snake-game)

一个用 Vue 3 + Vite 编写的独立小游戏，纯前端、无后端依赖。

## 直接玩（无需任何环境）

双击 dist/index.html 即可开始游戏（JS/CSS 已内联成单文件，支持 file:// 直接打开）。
也可以解压 snake-game-v1.0.0.zip 后双击里面的 index.html。

## 本地开发

npm install
npm run dev

## 重新打包

npm run build

构建后会自动执行内联脚本，产物 dist/index.html 为可双击运行的单文件版本。


## 手机 / 局域网游玩

1. 双击「启动局域网版.bat」（或命令行运行 node server.mjs）
2. 窗口会显示访问地址，例如 http://192.168.1.5:8080
3. 手机连同一个 Wi-Fi，用浏览器打开该地址即可
4. 手机支持在棋盘上滑动控制，触屏设备会自动显示方向按钮
## 操作

- 方向键 / WASD：移动
- 空格 / P：随时暂停 / 继续（界面上也有暂停按钮）
- R：重新开始
- 音效：吃食物、游戏结束、按钮点击有合成音效，可用 🔊/🔇 按钮随时开关
- 速度：下拉框选择 0.25x / 0.5x / 1x / 1.5x / 2x，游戏中随时可调
- 帮助：点击 ❓ 帮助 可查看完整操作说明
- 手机：支持在棋盘上滑动控制，触屏设备会自动显示屏幕方向按钮

## 规则

- 吃到红色食物得分 +10，蛇变长
- 撞墙或撞到自己游戏结束
- 速度会随吃到的食物数量逐渐加快
- 最高分和音效偏好保存在浏览器 localStorage
